=====================================================================
WHAT BROKE, AND IT WAS PACKAGING NOT CODE
=====================================================================
    The getter 'arabic' isn't defined for the class 'DailyHadith'

daily_hadith.dart DEFINES the arabic field. daily_hadith_card.dart USES it.

I shipped the first in v60 and the second in v61. They are interdependent, so
any tree that got v61 without v60 landing correctly has a card reading a field
that does not exist.

The code was never wrong. I split a two-file change across two bundles, which is
a packaging mistake and entirely mine.
