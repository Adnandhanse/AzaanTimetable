PLATFORM ADMIN LOGIN - INVISIBLE TEXT
=====================================================================
You diagnosed it correctly: the text was white.

The cause is a collision. That screen has a dark green background, so it set the
field text to white. But the app-wide inputDecorationTheme sets
`filled: true, fillColor: white` on every field. So the field was white and the
text on it was white.

Both fields now use dark charcoal text with a muted label, which is correct
against the white fill. I checked every other screen for the same collision —
this was the only one.
