2. THE BLANK SCREEN - MY FAULT, AND IT WAS LAUNCH-BLOCKING
=====================================================================
You were exactly right. _buildNoMasjidSelected showed a mosque icon and one
sentence and NOTHING ELSE. No button.

The floating "Change Masjid" button was the only route to the masjid search, and
I removed it in v41 because the Nearby Masjid quick action does the same thing -
without checking that the quick action lives INSIDE the home body, which only
renders once a masjid is already selected.

So a brand-new install had no way to select a masjid. The app was unusable from
first launch, and every new user would have hit it.

Fixed: a full-width "Nearby Masjid" button in that empty state, which is where
it belonged all along rather than floating over a list that does not exist yet.

I should have tested the first-run path when I removed that button. Removing a
control means checking every state that relied on it, and I checked one.

1. SAJDAH NOT SHOWING - IT WAS THERE, ON A SCREEN YOU DO NOT USE
=====================================================================
getArabicOnly() defaults to TRUE, so the app opens in Arabic-only mode. I put
the marker on the TRANSLATED verse rows only - invisible to anyone who never
switches modes, which is everyone by default.

Now marked in both:

  Translation mode   red dot and "Sajdah" beside the verse number
  Arabic-only mode   a red banner at the top of any page carrying one, naming
                     the ayah

Arabic-only renders one continuous block of text with no per-verse widgets to
attach anything to, so the page announces it instead of trying to mark a
position inside the flow.

Works in the Juz reader too. Sajdah positions are passed as INDICES, not verse
numbers, because a juz spans surahs and ayah 15 is ambiguous - the same reason
the bookmark works on indices.

Still shows the asterisk on Sad 38:24 and Al-Hajj 22:77, where the schools
differ.

4. JUZ NUMBER ON THE QURAN PAGE
=====================================================================
Under the surah name in the title bar: "2. Al-Baqarah / Juz 1".

It TRACKS AS YOU READ. A surah can span several juz - Al-Baqarah covers three -
so a fixed number would be wrong for most of it.

Added juzForVerse() to juz_boundaries.dart, which walks the boundaries backwards
and returns the last one that has already begun. Verified: every one of the 30
boundaries maps to its own juz, and spot checks pass - 2:141 is juz 1, 2:142 is
juz 2, 18:1 is juz 15, 36:1 is juz 22, 78:1 is juz 30.

The visible verse is estimated from scroll position rather than measured. It is
a label, so being an ayah or two out costs nothing, and measuring every row on
every frame would cost frames.
